# 判别测试（persona fidelity）——「像不像我」怎么量

> 状态：**骨架已建，需要你参与才能跑出数字**
> 题目集：`questions.jsonl`（30 题，固定种子抽样，可复现）

## 1. 为什么是判别测试

「像不像我」不能靠打分，因为没有标准答案可比对。
可行的方法是**判别**：给评判者看成对的回答，问"哪个更像本人"。
若评判者分辨不出，说明保真度已经足够高。

方法来自 Generative Agents（Park et al., UIST 2023）——
他们用这种方法验证生成的 agent 是否复现了本人的人格与行为倾向。

## 2. 核心设计：不需要评判者知道答案

这是本方法的关键，也是它可行的原因：

- 每题给评判者看**两个回答**：A 面来自本人真实语料，B 面来自赛博明翰
- 评判者**不知道哪个是本人**，只需选"更像本人的那个"
- 汇总所有评判者的选择正确率

| 正确率 | 含义 |
|---|---|
| ≈ 50% | 分辨不出 —— 保真度高（这是目标） |
| 显著 > 50% | 能分辨 —— 保真度不足，且能定位到具体差异 |
| 显著 < 50% | 比本人还像本人 —— 需检查是否过度美化 |

**注意：接近 50% 是好结果，不是失败。** 一开始容易理解反。
这个指标衡量的是"能否被区分"，不是"回答得多好"。

## 3. 流程

```
1. 用 questions.jsonl 的 30 题，分别取得：
   - A 面：本人真实语料（字段 self_reference，对应 KG 原文）
   - B 面：赛博明翰的回答（走 api/v1/chat，带上对应记忆）
2. 打乱 A/B 顺序（每题独立随机，避免位置偏见）
3. 发给 ≥5 位认识你的人做盲评
4. 汇总正确率与置信区间
```

## 4. 为什么是 5 位评判者

- 1 位：个体偏好噪声太大
- ≥5 位：可以算置信区间，结论才站得住
- 都必须是**认识你本人**的人，否则无法判别

## 5. 当前限制（诚实列出）

- **30 题是自动从 KG 抽样生成的**，措辞是模板填充（"关于「X」，能说说你是怎么想的吗？"）。
  你应当**人工过一遍**，改写或替换掉不像自己会问的题目——
  题目本身不像，测出来的就不是保真度。
- 题目生成时已排除含真实人名与明显私密标记的节点（121/146 合格），
  但**边界仍可能漏**，发出去前请自己看一遍。
- 本骨架**不解决 B 面怎么生成**：需要后端跑起来 + LLM 可用。
  若 API 不通，可先手工用 KG 内容构造 B 面做小规模预演。

## 6. 与「事实准确性」区分

判别测试测的是**风格与倾向的相似度**，不是事实对错。
一个回答可以很像本人但事实错误，也可以事实正确但不像本人。
两者要分开测，不要用一个指标代替另一个。
