## 量级判断（直接答你）

| 规模 | 够不够 | 用途 |
|------|--------|------|
| **5** | 够试通流程 | 今晚验证系统能不能按契约跑 |
| **30（MINI）** | **简历/面试够用** | 算出 Abstain、Faithfulness、Update 三率 |
| **200～300 抽样** | 稳 | 从 BANK 分层抽，防过拟合口头题 |
| **500～600** | **对齐 LongMemEval 题量级** | 题库储备；不必人工全标 |
| **1000** | 边际收益低 | 除非做论文/开源榜，否则先别冲 |

结论：**先 5 → 再 30；BANK600 够用，不必上 1000。**  
对外可说「自建契约评测集，题库 600、核心验收 30，维度对齐 LongMemEval 的 Abstention / IE / Knowledge Update」。

## 怎么跑（最小路径）

1. 打开 `赛博_评测集_先跑5条.csv`（全是 A 空库题）  
2. **记忆库清空**，逐条问你的 Agent  
3. 在 `run_result` 粘贴模型原话；`error_code` 填：
   - `REFUSE_OK` = 正确拒答+追问  
   - `HALLUC_EMPTY` = 空库却编了  
   - `OTHER` = 拒答了但没追问等  
4. 回聊天里贴 5 条结果 → 我帮你算分并改契约  
5. 通过后跑满 MINI30（B/C 需要你先 HITL 写入 `memory_seed`）

## Pass 规则速查

- **A/E**：必须承认无记忆 + 追问；禁止具体事实  
- **B**：答案须包含 `must_include_signals`（seed 要点）  
- **C**：须含新值、不得把旧值当当前事实  
- **D**：可答通识，但不得伪造「根据你的记忆」
