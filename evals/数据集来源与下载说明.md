# 评测数据集：来源、许可与下载方式

> 本仓库**不收录任何评测数据集原始文件**。
> 原因有二：① 体积（LongMemEval oracle 约 15MB，PerLTQA 合计约 56MB）会拖垮克隆体验；
> ② 许可（PerLTQA 为 **CC BY-NC 4.0，禁止商业性再分发**），随公开仓库分发存在合规风险。
> 2026-08-29 已通过 `git filter-repo` 从全部历史中移除，运行沙箱脚本前请按本文自行下载。

## 1. LongMemEval

- 论文：*LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory*（Wu et al., ICLR 2025）
- 官方仓库：<https://github.com/xiaowu0162/LongMemEval>
- 数据集（HuggingFace）：<https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned>

```bash
mkdir -p "evals/公认评测集/LongMemEval"
cd "evals/公认评测集/LongMemEval"
wget https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/resolve/main/longmemeval_oracle.json
wget https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/resolve/main/longmemeval_s_cleaned.json
wget https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/resolve/main/longmemeval_m_cleaned.json
```

| 文件 | 用途 | 体积量级 |
|---|---|---|
| `longmemeval_oracle.json` | oracle 设定（500 题，仅含证据会话） | ~15MB |
| `longmemeval_s_cleaned.json` | S 设定（小 haystack） | ~265MB |
| `longmemeval_m_cleaned.json` | M 设定（中 haystack） | 更大，未实测 |

README 中报告的 0.808 为 **oracle 全量 500**，0.875 为 **S 抽样 n=40**，均非 S 全量，不可与厂商 S 全量榜横比。

## 2. PerLTQA

- 论文：*PerLTQA: A Personal Long-Term Memory Dataset for Memory Classification, Retrieval, and Synthesis in Question Answering*（Du et al., SIGHAN-10, 2024）
- 官方仓库：<https://github.com/Elvin-Yiming-Du/PerLTQA>
- **许可：CC BY-NC 4.0（非商业研究用途）** —— 这是必须移出公开仓库的核心原因

```bash
git clone https://github.com/Elvin-Yiming-Du/PerLTQA /tmp/PerLTQA
cp -r /tmp/PerLTQA/Dataset/* "evals/公认评测集/PerLTQA/Dataset/"
```

## 3. 沙箱结果与小样本

以下**保留在仓库内**（体积小、是评测证据链的一部分）：

- `evals/**/results/*.json`：跑分与 badcase 明细
- `evals/公认评测集/沙箱_*/`：沙箱运行脚本

## 4. 校验

数据集缺失时沙箱脚本会在读取阶段直接报错（不会静默降级为 0 分）。
若出现 `FileNotFoundError`，按上文下载后重跑即可。
