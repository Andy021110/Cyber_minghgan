# 赛博明翰 2.0 · 上帝指令小白指南

> 本指南面向第一次使用「上帝指令」功能的普通用户。
> 无需了解任何数据库或 JSON 知识，用自然语言说话即可。

---

## 什么是「上帝指令」？

在和赛博明翰聊天时，如果你的消息以 `/` 开头，系统会切换到**数据库管理模式**，由一个专属的 AI 数据库管理员来理解并执行你的意图。

**普通聊天** → 直接输入消息，赛博明翰会用人格回应  
**上帝指令** → 以 `/` 开头，系统直接操作底层心智图谱

> ⚠️ 上帝指令与日常对话完全隔离，不会污染聊天记录。

---

## 查（Retrieve）——检索记忆

**用途**：在赛博明翰的心智图谱中搜索相关记忆节点。

**格式**：
```
/检索 <关键词>
```

**示例输入**：
```
/检索关于孤独感的记忆
/搜索他对技术选型的态度
/查一查跟社交有关的节点
```

**终端回显示例**：
```
[系统后门] 收到指令：检索关于孤独感的记忆
[系统后门] 工具：retrieve_memory  参数：{"keyword": "孤独感"}
[系统后门] 检索结果（2 条）：
  1. [Id] 亲密渴望下的原始力比多驱力
     uuid: a1b2c3d4...
     主体对陌生人社交平台表现出强烈的探索性询问，底层驱动为原始亲密需求…
  2. [Ego] 社交场合的延迟满足协商
     uuid: e5f6g7h8...
     在半夜两点面对即时匹配时，Ego 引入时间变量作为缓冲…
```

**小白提示**：关键词越具体越好，推荐用情绪词、人名、行为动词。"孤独""实习""弓佳彤""脚本"这类词比"他""什么"效果好得多。

## 增（Create）——写入新记忆

**用途**：向心智图谱中手动添加一条新的动力学节点，记录新发现的行为模式或偏好。

**格式**：
```
/新增 <描述你想记录的内容>
```

**示例输入**：
```
/新增一条记忆：他喜欢用脚本自动化处理重复性杂活，这是他的行动原则
/帮我在 Ego 层加一条：面对延毕危机时选择用工作填满时间来回避焦虑
/新增：他在做技术决策时会主动回避风险更高但更有趣的方案
```

**终端回显示例**：
```
[系统后门] 收到指令：新增一条记忆：他喜欢用脚本自动化…
[系统后门] 工具：create_memory  参数：{"layer": "Ego", "event_label": "脚本自动化偏好", ...}
[系统后门] 操作成功 → label=脚本自动化偏好 | layer=Ego | uuid=0b13b20e…
```

**小白提示**：  
- 你不需要指定层级（Id / Ego / Superego），AI 管理员会根据内容自动判断  
- 如果你想强制写入某一层，可以在指令里说明，例如"在 Id 层新增"  
- 写入的内容会**永久保存**到本地 JSON 文件，重启程序后依然有效

## 改（Update）——修改已有记忆

**用途**：更正或补充心智图谱中某条节点的描述内容。

**重要须知：你完全不需要知道任何 UUID 或 ID！**  
直接用自然语言描述你想改的那条记忆是什么，系统会自动先搜索、再定位、再修改。

**格式**：
```
/修改 <描述目标记忆> 把 <某字段> 改成 <新内容>
```

**示例输入**：
```
/把「脚本自动化偏好」那条记忆的描述改得更详细一点，加上"尤其是数据处理类任务"
/更新关于孤独感的那条 Id 层记忆，把证据字段换成最新的对话原文
/修改技术决策风险规避那条，把 batch_id 改为 Batch8
```

**终端回显示例**：
```
[系统后门] 收到指令：把「脚本自动化偏好」那条…
[系统后门] 工具：retrieve_memory  参数：{"keyword": "脚本自动化偏好"}
[系统后门] 检索结果（1 条）：
  1. [Ego] 脚本自动化偏好
     uuid: 0b13b20e73d846648665b5a24c545e1b
     ...
[系统后门] 工具：update_memory  参数：{"node_uuid": "0b13b20e...", "description": "...（新内容）"}
[系统后门] 操作成功 → label=脚本自动化偏好 | layer=Ego | uuid=0b13b20e…
```

**小白提示**：  
- 系统会自动先「查」再「改」，这是两步操作，你只需说一句话  
- 如果检索到多条同名记录，AI 会选最匹配的那条；如果你想精准指定，可以在指令里加更多上下文  
- `uuid` 和 `layer` 两个字段**永远无法被修改**（这是系统内置的安全锁）

## 删（Delete）——永久移除记忆

**用途**：从心智图谱中彻底删除一条动力学节点。**此操作不可撤销。**

**重要须知：同样不需要 UUID！**  
告诉系统你想删哪条，它会先找到它，再请你确认（通过下一步的交互），然后执行删除。

**格式**：
```
/删除 <描述目标记忆>
```

**示例输入**：
```
/删除「脚本自动化偏好」那条记忆
/把关于技术风险规避的那条 Ego 节点删掉
/删除所有 batch_id 为 TestBatch 的节点
```

**终端回显示例**：
```
[系统后门] 收到指令：删除「脚本自动化偏好」那条记忆
[系统后门] 工具：retrieve_memory  参数：{"keyword": "脚本自动化偏好"}
[系统后门] 检索结果（1 条）：
  1. [Ego] 脚本自动化偏好
     uuid: 0b13b20e73d846648665b5a24c545e1b
     ...
[系统后门] 工具：delete_memory  参数：{"node_uuid": "0b13b20e..."}
[系统后门] 删除成功 ✓
```

**小白提示**：  
- 删除是**永久性操作**，执行前请确认关键词描述的是你真正想删的节点  
- 如果你只是想「暂时不用」某条记忆，可以考虑用「改」把它的描述标记为 `[已废弃]`，而不是直接删除  
- 一次只建议删一条；批量删除容易误伤相关节点

## 自动反刍机制——系统的「自我进化」

### 什么是反刍？

每当你和赛博明翰**连续完成 5 轮普通对话**后，系统会在后台自动触发一次「记忆反刍」。它会把最近这 5 轮的对话提取出来，交给一个专属 AI 分析：

> "用户在这段对话里，有没有流露出值得长期记录的新习惯、偏好或行为规律？"

### 终端弹出 `(Y/N)` 时怎么办？

如果 AI 分析出了新特征，终端会挂起并显示：

```
[反刍引擎] 正在分析最近 5 轮对话...
[系统反刍] 提取到新特征：用户习惯用脚本自动化处理重复性杂活，定为默认行动原则。
是否写入底层图谱？(Y/N):
```

- **输入 `Y` 并回车**：新特征将被永久写入心智图谱的 Ego 层，下次对话时赛博明翰会自动参考它
- **输入 `N` 并回车**：跳过本次写入，对话继续，图谱不变
- **直接按 Ctrl+C**：等同于 N，安全跳过

如果 AI 判断这 5 轮聊的是闲话、没有值得提炼的新内容，则不弹窗，系统静默继续。

### 反刍之后上下文会被清理

反刍触发后，系统会自动「垃圾回收」——把中间冗长的聊天记录删掉，只保留最近 2 轮，以防止对话越来越长导致卡顿或报错。**你感知不到这个过程，对话可以无缝继续。**

## 避坑指南

### ✅ 指令越清晰，效果越好

系统背后是一个 AI 数据库管理员，它依赖你的自然语言来判断意图。指令模糊会导致它检索错误的节点。

| 效果差的指令 | 更好的写法 |
|---|---|
| `/改一下那条` | `/把关于孤独感的那条 Id 层记忆描述改得更简洁` |
| `/删掉它` | `/删除标签为「技术决策中的风险规避」的节点` |
| `/加一条` | `/新增一条 Ego 层记忆：他在面对截止日期压力时会切换到高效执行模式` |

### ✅ 改和删之前可以先查

不确定某条记忆是否存在、叫什么名字？先用 `/检索 <关键词>` 确认内容，再执行修改或删除，是最稳妥的操作方式。

### ⚠️ 上帝指令不是聊天

`/` 开头的输入直接进入数据库模式，赛博明翰的人格不参与这个过程。如果你想和他聊「你对这条记忆有什么看法」，请不要加 `/`，直接用普通对话方式问他。

### ⚠️ 删除无法撤销

图谱没有版本控制，删除立即生效且无法恢复。不确定时用「改」加标记代替「删」。
