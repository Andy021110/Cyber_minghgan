## 1. 需求分级（真需求 vs 伪需求）

### 判据

用什么区分？不用"感觉重要"，用三条可观测标准：

| 判据 | 说明 |
|---|---|
| **后果不可逆性** | 做错了能不能撤回。隐私泄露、数据丢失不能撤回 → 最高优先级 |
| **是否直击定位** | 定位是「可信的个人代理，深度在记忆治理」。不直接服务于"可信"或"记忆治理"的 → 降级 |
| **现有证据** | 本项目里有没有实测证据（badcase / 审计数据）。有证据 = 真问题；只有想象 = 待验证 |
