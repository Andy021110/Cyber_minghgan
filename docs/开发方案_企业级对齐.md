## 5. 关键决策记录

1. **embedding 选本地 BGE**：用户决策选 A（bge-small-zh-v1.5），本地运行、无外网依赖、不烧 API；默认 Zero provider 保证测试/CI 零依赖
2. **Mock LLM 用「录回放」**：首次跑真 API 录响应 → 存 fixture → 测试用 fixture 回放（不烧钱、可 CI）
3. **LangGraph 放阶段 3**（已完成）：等测试地基打好再重构循环（有回归保护才敢动核心）。
   关键约束已写进 `agent/graph.py` 注释：interrupt 前不得有副作用、禁止 try/except 包裹、
   单节点只调一次 interrupt —— 依据是官方 Interrupts 文档「节点恢复时从头重跑」
4. **HITL 不削弱**：用 interrupt 强化，审核语义保持（approved_kg/log/rejected 三档）
5. **测试隔离**：所有测试用临时目录/临时库，绝不碰真实 KG/L0 数据
6. **遗忘只归档不删除**：自动遗忘只做「提名 + 归档」，删除必须人工确认（不可逆操作）。
   依据：认知会变，今天看似无用的记忆可能是未来冲突裁决的证据
7. **冲突用 supersede 而非覆盖**：直接 update 会丢失「曾经怎样」的演变链；
   取代链保留旧事实（归档 + superseded_by），检索只返回最新
8. **短期/长期记忆严格分离**：短期=thread-scoped checkpointer（解决上下文窗口），
   长期=L0/L1（解决跨会话）。把 KG 全塞 system prompt 是已废弃的早期做法
