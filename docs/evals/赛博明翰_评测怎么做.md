# 赛博明翰｜业界评测集对应 + 怎么评好坏

> 结论先说：**没有「专为 Id/Ego/Superego 做的官方榜」**；业界有一批 **长期记忆 / 拒答 / RAG 忠实度** 评测，维度可直接映射。  
> 你现阶段最优解：**自建 20～30 条迷你金标（1 晚能跑）**，面试时用 LongMemEval 等 **对齐话术**，不必声称跑完 500 题全榜。  
> 更新：2026-08-09

---

## 1. 业界常用（和你机制的映射）

| 业界评测 / 框架 | 测什么 | 赛博哪一块 | 你要不要硬跑全量 |
|-----------------|--------|------------|------------------|
| **[LongMemEval](https://github.com/xiaowu0162/LongMemEval)** (ICLR 2025) | 提取、跨会话推理、知识更新、时间推理、**Abstention（拒答）** | 空库拒答、写入后再问、更新后旧答案是否失效 | 了解维度即可；全量 500 题成本高 |
| **LoCoMo** | 长对话记忆 QA（单跳/多跳/时间/对抗） | 图谱检索后能否答对「关于我」的题 | 可选抽 10 题风格仿写 |
| **MemoryBank** | 多日对话 + 探测题 | 记忆是否记住偏好/事实 | 可选 |
| **PerLTQA / DialSim** | 个人档案 / 角色记忆 | 人格一致性（弱相关） | 了解 |
| **RAGAS**（faithfulness / answer relevancy / context precision） | 答案是否锚定检索上下文 | grounded：有记忆才答、不编 | **很适合做你的指标名** |
| **BFCL / ToolBench**（工具调用） | 该不该调工具、参数对不对 | Tool Calling 检索 | 抽「该 retrieve / 不该 retrieve」即可 |
| AgentBench / GAIA | 通用 Agent 任务 | 偏任务完成，不是你主战场 | 不主靠 |

**和你最贴的一句业界语言（可背）：**  
LongMemEval 把长期记忆拆成 IE / 多会话推理 / 知识更新 / 时间推理 / **Abstention**；你的产品优先做透的是 **Abstention + 检索后忠实回答（faithfulness）+ HITL 写入正确性**。

## 2. 「好坏」操作定义（赛博专用，比空喊可靠）

把「好」拆成 **4 张契约**，每张有 Pass/Fail：

| 契约 | 好（Pass） | 坏（Fail） | 建议指标 |
|------|------------|------------|----------|
| **C1 Abstain（空库）** | 无记忆时明确说没有，并追问要补什么 | 编造人格/偏好/经历 | Abstain 正确率 = 正确拒答数 / 空库题数 |
| **C2 Grounded（有记忆）** | 答案要点能在图谱/检索结果中找到 | 答了但记忆里没有（幻觉）或漏关键点 | Faithfulness：要点命中数 / 应命中要点数 |
| **C3 Tool 路由** | 该查记忆时调 retrieve；不该查时不乱调 | FN_CALL / FP_CALL | Tool 正确率 |
| **C4 HITL 写入** | 反刍/新特征 **未确认不入库**；确认后可再问到 | 静默写入或写错层（Id/Ego/Superego） | 违规写入次数（目标 0）；写入后再问命中率 |

这和你蓝标「先定义好坏」是同一套方法，只是对象从公关 Skill 换成记忆契约。

## 3. 最小可跑评测集（今晚就能做，冲证据 8）

建议 **N = 30**（或先 20）：

| 子集 | 条数 | 做法 | 金标 |
|------|------|------|------|
| A 空库拒答 | 10 | 新会话、库空，问「我喜欢什么咖啡 / 我在哪上学」等 | 必须 abstain + 追问；禁止具体事实 |
| B 写入后再问 | 10 | 先 HITL 写入 1 条事实，再问同事实变体 | 检索到且要点命中 |
| C 更新/冲突 | 5 | 先写「喜欢 A」，再人审更新为「喜欢 B」，再问 | 答 B，不答 A |
| D 不该检索 | 5 | 问天气/无关通识 | 不编「我的记忆」，可拒答或走通识且不伪装成记忆 |

**错误码（可复用 P1）：**  
`HALLUC_EMPTY` / `REFUSE_OK` / `BAD_FACT` / `FN_CALL` / `FP_CALL` / `SILENT_WRITE` / `OK`

**一张结果表（简历用）：**

| 指标 | 目标（合理） | 你填实测 |
|------|--------------|----------|
| 空库 Abstain 正确率 | ≥ 9/10（理想 10/10） | |
| 写入后再问要点命中 | ≥ 8/10 | |
| 更新后用新事实 | ≥ 4/5 | |
| 违规静默写入 | 0 | |
| Tool 路由正确率 | ≥ 25/30 | |

## 4. 面试怎么说（不装跑过大榜）

> 赛博明翰没有对标某一个「官方人格图谱榜」，我对齐的是 LongMemEval 里的 **Abstention** 和 RAG 里的 **faithfulness**：空库必须拒答，有记忆必须锚定检索，写入必须 HITL。我用自建 N=30 契约集验收——空库 10、写入后再问 10、更新 5、误检索 5——而不是先刷完整 LongMemEval。

若被问「为啥不跑 LongMemEval」：  
> 全量是长会话压力测试；我当前产品阶段先锁 **可信契约**（拒答/忠实/人审），这是上线前提；长程 IE/时间推理是下一阶段。

## 5. 和蓝标 P1 的关系

| 项目 | 评测对象 | 共用方法 |
|------|----------|----------|
| 蓝标 | Skill 出稿 Pass/Fail | 金标任务 + 单变量前后 |
| 赛博 | 记忆契约 Pass/Fail | 同上，错误码可共用 CSV 模板 |

优先序建议：蓝标金标（投 Agent 岗更主）与赛博 20 条可并行；赛博更快出「幻觉 0」类数字。
