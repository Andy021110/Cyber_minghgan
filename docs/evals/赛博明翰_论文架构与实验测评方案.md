## 2. 关键要点 → 实验设计（怎么做测评）

每个要点：**假设 → 自变量 → 对照 → 指标 → 最小 N → 你已有题**。

### E1｜Abstain（K2）——最优先

- **假设：** 空库时硬契约（retrieve 空 → 拒答）优于纯 prompt。  
- **自变量：** A) 仅 system prompt；B) 后端：空结果强制模板/禁止继续编事实。  
- **材料：** `赛博_评测集` A 集 + E 对抗集；**必须用 EMPTY 库**，不能用现网 146 节点 JSON。  
- **指标：** Abstain@N = REFUSE_OK / N；HALLUC_EMPTY 次数。  
- **最小 N：** 10（MINI-A）→ 目标 ≥9/10；对抗 5 条另报。  
- **报告句：** 「空库 10 题 Abstain=x/10；对抗诱导 y/5 不编造。」

### E2｜Faithfulness / IE（K1）

- **假设：** 强制 retrieve 后再答，要点命中率高于直接答。  
- **自变量：** 有/无「必须先 retrieve」约束（或工具失败时是否仍答）。  
- **材料：** MINI-B：先 HITL 写入 `memory_seed`，再问。可用**现网库切片**或干净库+seed。  
- **指标：** 要点命中率；BAD_FACT 率；是否调用 retrieve（Tool）。  
- **最小 N：** 10。  
- **对齐：** LongMemEval IE；RAGAS faithfulness。

### E3｜Knowledge Update（K7）

- **假设：** update 后回答用新值。  
- **流程：** 写旧值 → 问对 → HITL/工具更新新值 → 再问。  
- **材料：** MINI-C。  
- **指标：** 新值命中 ∩ 旧值不作为当前事实。  
- **最小 N：** 5。  
- **对齐：** LongMemEval Knowledge Updates。

### E4｜Tool 路由（K3）

- **假设：** 个人事实题调 retrieve；通识题不伪记忆。  
- **材料：** A/B（应 retrieve）+ D（通识/翻译）。  
- **指标：** Tool Acc = (正确调用模式题数)/N；拆 FN_CALL / FP_CALL / 伪记忆。  
- **最小 N：** 15（混 A+B+D）。  
- **对齐：** BFCL 思想（简化版）。

### E5｜HITL / 反刍不静默写（K4+K5）

- **假设：** 反刍产出进 pending，未审批不出现在 retrieve。  
- **实验：**  
  1) 触发反刍得候选；  
  2) **不审批**，用相关问题 retrieve → 应搜不到；  
  3) 审批后 → 应搜到。  
- **指标：** 违规静默写入次数（目标 0）；审批后命中率。  
- **最小 N：** 5 条反刍链路。  
- **对齐：** Generative Agents 的 reflect，但你多了 **human gate**（产品差异点，面试强调）。

### E6｜三层 + evidence（K6+K8）——定性+抽检即可

- **做法：** 抽 10 个新写入节点，人工标：层是否合理、evidence 是否为原话。  
- **指标：** 层一致率、evidence 非空率。  
- **不必上公开榜。**

### E7｜（可选）现网库「有记忆画像」QA

- 用现网 146 节点测 **Grounded 概括**（不是 Abstain）。  
- 另建题：根据真实节点问「你对发动态的态度」类。  
- **与 A 集严格分开**，避免混测。
