# 关键决策记录（ADR）

> 用途：**关键决策有充分论证依据**
> 每条含：背景 / 选项 / 决定 / 依据 / 后果 / 状态

---

## ADR-001 · embedding 选本地 BGE，不依赖外部 API

- **背景**：需要语义检索，但不想引入付费/联网依赖
- **选项**：A 本地 BGE ｜ B OpenAI/DeepSeek embedding API ｜ C 云端向量库
- **决定**：**A（bge-small-zh-v1.5）**，配 `ZeroEmbeddingProvider` 兜底
- **依据**：本地运行无外网依赖、不烧 API；Zero provider 保证测试/CI 零依赖（用户 2026-08-21 决策）
- **后果**：环境变量 `CYBER_EMBEDDING_PROVIDER=bge` 切换；未装 sentence-transformers 时自动退化为关键词检索

## ADR-002 · 编排用 LangGraph（而非 LangChain agents 或自研）

- **背景**：手写 while 循环无法回放/中断/测试
- **决定**：**LangGraph**
- **依据**（官方 overview 原文）：
  > "LangGraph is a low-level orchestration framework and runtime for building, managing, and deploying long-running, stateful agents."
  > "focused on ... **durable execution, streaming, human-in-the-loop**, and more."
  多 Agent（subagents）是"on top of LangGraph"的一层，**不是 LangGraph 本身**
- **后果**：我们真正需要的三件事（状态机回放、短期记忆持久化、写操作中断）正是其核心能力，且对单 Agent 适用

## ADR-003 · HITL：写操作必须 interrupt，三档审批

- **背景**：自动写入会污染人设
- **决定**：写类工具走 `interrupt()` + `Command(resume=)`，语义 `approved_kg` / `approved_log` / `rejected`
- **依据**（官方 Interrupts 文档）：节点恢复时**从头重跑** → 三条硬约束：
  1. `interrupt()` 前不得有副作用　2. 禁止 try/except 包裹　3. 单节点只调一次
- **后果**：审批语义与既有 `pipelines/hitl_review.py` 三档保持一致

## ADR-004 · 遗忘只归档不删除

- **背景**：低频记忆占空间、干扰检索
- **决定**：`importance × 0.5^(Δt/180)` 衰减，低于阈值且久未访问 → **归档**（软删除），不物理删除
- **依据**：删除不可逆；今天看似无用的记忆可能是未来冲突裁决的证据。默认 dry-run，需 `--apply`
- **后果**：可回滚；幂等（已归档节点被跳过）

## ADR-005 · 冲突用 supersede 而非覆盖

- **背景**：「喜欢美式」→「改喝手冲」若直接覆盖，会丢失演变链
- **决定**：新节点取代旧节点，旧节点 `superseded_by` + 归档；`update_with_version` 保留 history（上限 5）
- **依据**：认知会变，保留过程才能解释"为什么变了"
- **后果**：事实不丢、检索只返回最新

## ADR-006 · 三层（Id/Ego/Superego）不可证明，只验证"有用"

- **背景**：用户追问"有没有数学推导"
- **决定**：**不声称有数学证明**，改为可测量的有用性验证
- **依据**：该结构借自弗洛伊德模型，现代心理学不作为已验证科学理论。实测可分性 **0.589 vs 基线 0.411**（已修正标签泄漏）
- **边界**：0.589 只证明标注**内部一致**，不证明对应真实心理结构（证明后者需预测效度实验）
- **后果**：面试话术为"建模坐标系 + 可分性验证 + 准备做消融"，而非"基于理论所以科学"

## ADR-007 · 图检索：方向对，但现在不建全图

- **背景**：是否用图链接做记忆检索
- **选项**：建全图 ｜ 不建 ｜ 折中
- **决定**：**折中**——先接 interactions（自带 trigger→resolution），等分题型召回率数据再决定
- **依据**：
  - 反方：全库边数=0、规模仅 16.2k tokens → 当前规模下图检索优势≈0
  - 正方：Zep/Graphiti 在 LongMemEval 63.8% vs Mem0 49.0%，增益集中在时序(+38%)与多跳(+31%)
  - 综合：图的价值 = f(规模, 查询类型)，我们现在在"小规模"象限
- **后果**：先拿到数据再决策，避免拍脑袋上马或拍脑袋否定

## ADR-008 · 定位：可信的个人代理，不做通用助理

- **背景**：是否对标 Hermes 堆工具生态
- **决定**：**不做通用助理**。深度放在记忆治理（不瞎编、知道边界、能溯源）
- **依据**：Hermes 已有 17 万星，比工具数量必输；而"让 AI 代表你跟面试官说话"时，可信度 > API 数量
- **三个不做**：微信个人号自动回复（合规）｜冒充本人欺骗面试官（诚信）｜堆通用工具生态

## ADR-009 · MCP：暂缓

- **背景**：用户最初期待用 MCP 让 Agent 操作外部服务
- **决定**：**暂缓**
- **依据**：现在做 MCP 是"我们去调别人的工具"，无差异化；将来做是"别人来用我们的记忆"，那才是壁垒。且 MCP 会绕过 HITL
- **触发重评条件**：当"助理的记忆层"定位成立时（即记忆质量已验证）

## ADR-010 · 拒答策略：后果主导，语档次之

- **背景**：A2 拒答阈值与 A3 话题边界原为两个问题
- **决定**：**合并为话题敏感度三档**（open / guarded / closed）
- **依据**：用户 2026-08-30 决策（能力/经历体验优先、私密信任优先）；推理得出**后果是主导项**——语料再充分、后果高也不答
- **关键推论**：两策略不是妥协关系，各适配自己象限
- **落地**：`visibility` 从两态扩为三态

## ADR-011 · 参数一律标注"待标定"

- **背景**：`vector_alpha=0.4`、`half_life=180`、`keep_last=6`、`compact_threshold=12`、`min_effective=1.5` 全是拍定值
- **决定**：代码与文档中标注"待标定"+ 标定方法，不自称有依据
- **依据**：拍定的参数伪装成设计决策是技术负债
- **标定方法**：λ 用网格搜索 + A/B 跑分；half_life 用访问间隔做存活分析拟合
